# Lessons

- 2026-11-13 · Google Workspace can't transfer ownership outside the organisation, even for admins. Copying as the new owner is the no-cost route.
- 2026-11-13 · Standard project subfolders created by the old account are owned by it too, so a twin appears beside each. Mark the original `[MOVED]` or the tree shows duplicate names.
- 2026-11-13 · A resumed pass that re-walks from the top can spend its whole time budget on finished folders. Record finished folders per pass.
- 2026-11-13 · Apps Script `getFolderById` returns an object for a file id instead of failing. Mocks must copy real API quirks; decide file vs folder by MIME type.
- 2026-11-13 · clasp's sign-in page uses whichever Google account the browser picks, even with a login hint. Confirm the account before pushing.
- 2026-11-13 · First built as a pasted editor script, then rebuilt to standard (repo, tests, gate, CI). Repo first next time.
